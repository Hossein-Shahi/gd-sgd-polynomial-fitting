# Supplementary Material: Code and Data

Code and data accompanying the manuscript
"Stability Thresholds and Noise Floors: Comparing Gradient Descent
and Stochastic Gradient Descent on Polynomial Regression".

Authors: Hossein Shahi (Southeast Missouri State University), Juefei Yuan
(Southeast Missouri State University), Zahra Zolnourian (Independent
Researcher).

Both optimizers are implemented in pure Python (no NumPy, no ML libraries).
Every number and figure in the paper can be regenerated with the scripts below.

## Requirements

Python 3.8+. `matplotlib` (and `pillow`, used by matplotlib) are needed only to
render the figures; the optimizers themselves have no dependencies. `numpy` is
required only by `verify_closed_form.py`, which exists solely as an *independent*
cross-check of the closed-form minima computed in pure Python elsewhere in this
package.

```
pip install matplotlib pillow numpy
```

## Reproducing the core grid (Sections 4.1-4.4)

```
python run_experiments.py     # 180 training runs -> results.json, results_summary.csv, four core figures
python make_figures.py        # remaining figures + Appendix A gallery (asserts seed-0 runs match results.json)
python verify_closed_form.py  # closed-form minima quoted in Sections 4.1 and 5.4
python stationarity_check.py  # noise-floor exclusion criterion (Section 4.7)
```

Run all commands from this folder. Figure file -> paper mapping: fig1_fit_deg3 -> Fig. 1,
fig4_degrees -> Fig. 2, fig3_lr_compare -> Fig. 3, fig_instability -> Fig. 4,
fig2_loss_deg3 -> Fig. 5, fig_weights_deg3 -> Fig. 6, figA_* -> the nine per-configuration record figures in Appendix A.

## Reproducing the extended experiments (Sections 4.5-4.9)

`run_all_extended.py` reproduces every extended result and figure in the paper:
the equal-update-budget comparison (E1), the stability-threshold measurement (E2),
the mini-batch noise-floor sweep with the i.i.d.-sampling control (E3), the
synthetic-twin grid with train/test split (E4), and the decaying-step runs (E5),
followed by all derived statistics and Figures 7-11.

```
python3 run_all_extended.py
```

The script is fully seeded and resumable: it saves results incrementally to
`results_extended.json` and `results_extras.json` and skips completed blocks on
restart. It also writes `synthetic_dataset.txt` (the synthetic twin, generator
seed 123) and the new figures into `figures/`. Pure Python only; matplotlib is
required for the figures. A complete run takes a few minutes on a modern machine.

## Files

- `gradient_descent.py`, `stochastic_gradient_descent.py` - the two optimizers,
  pure Python, with the feature construction and clipping safeguards described in
  Section 3.4.
- `main.py` - minimal standalone driver for a single GD/SGD comparison; useful as
  a readable entry point, not required to reproduce the paper.
- `run_experiments.py`, `make_figures.py` - the core 3x3 grid and its figures.
- `run_all_extended.py` - the extended suite (E1-E5), including the pure-Python
  Gaussian elimination and power iteration used for the closed-form references.
- `verify_closed_form.py` - independent NumPy cross-check of the closed-form minima.
- `stationarity_check.py` - reproduces the exclusion-criterion analysis of
  Section 4.7: the threshold-sensitivity table, and (with `--full`) the
  stationarity diagnostic that reruns the excluded points at 300,000 updates.
- `Part1_x_y_Values.txt` - the real dataset (100 points).
- `synthetic_dataset.txt` - the synthetic twin (regenerated by `run_all_extended.py`).
- `results*.json`, `results_summary.csv` - recorded outputs.
- `figures/` - all figures in the paper.

## Data provenance

The dataset (Part1_x_y_Values.txt, 100 points) originates from a graduate course
project; its generating process is not documented, and the paper characterizes it
empirically.
